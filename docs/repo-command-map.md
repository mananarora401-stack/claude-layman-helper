# Task Navigation Guide

This guide explains how to approach tasks in a structured and beginner-friendly way when using Claude or any AI assistant.

## Step 1: Clarify the goal

Start by asking: What am I actually trying to achieve?

Examples:

- understand a repository
- fix a bug
- explain code
- create a plan
- optimize a process
- summarize research

If the goal is unclear, the answer will also be unclear.

## Step 2: Gather context

Before asking for help, collect the important background:

- where is the project?
- what is the repository trying to do?
- what is the issue?
- what do you want the final output to look like?
- what constraints exist?

## Step 3: Ask for a plan before doing heavy work

This is one of the best habits for beginners.

Ask for:

- a short summary
- a list of likely tasks
- the safest next steps
- what files to inspect first
- what to avoid

## Step 4: Ask for simple explanations

When working with technical tasks, ask:

- explain this in plain English
- avoid jargon
- give me the easiest option first
- tell me why this matters

## Step 5: Request validation

After an answer or fix, ask:

- how do I check if it worked?
- what should I look for?
- what if it fails?
- what is the fallback option?

This helps reduce confusion and mistakes.

## Good task structure

A good task request usually looks like this:

1. Goal
2. Files or system involved
3. Current problem
4. Desired outcome
5. Constraints
6. Expected answer format

## Example

"I want to understand this repository and know the best way to begin. I am a beginner and need simple instructions. Please explain the purpose, key files, likely first steps, and the safest path forward."

## The rule to remember

Do not ask broad questions when you can ask clear ones.

Instead of:

"Can you help with this repo?"

Try:

"I want to understand this repo as a beginner. Please explain the structure, the main files, and the first steps I should take. Use simple language and avoid jargon."

That produces far better output.

## Helpful question patterns

- What should I do first?
- What files matter most?
- What is the simplest path?
- Why is this happening?
- What are the safest options?
- How can I confirm the result?

## Final advice

Use Claude as a teacher, planner, and reviewer.

Ask it to:

- explain
- simplify
- prioritize
- structure
- validate
- suggest next steps

That makes the process much easier for non-technical users.
