# Prompt Playbook

This file is a simple guide for turning vague requests into strong, clear prompts.

## The 5-part prompt formula

Every effective prompt should contain:

- Role
- Goal
- Context
- Constraints
- Output format

## Example structure

"Act as [role]. I want to [goal]. Context: [background]. Constraints: [limitations or preferences]. Please provide [final answer format]."

## Beginner-friendly examples

### Example 1: Ask for explanations

"Act as a teacher for a beginner. Explain what this repository does in simple English. Focus on the purpose, main files, and the first steps a new user should take. Keep it easy to understand."

### Example 2: Ask for a plan

"Act as a project manager and technical guide. I want to improve this project without coding experience. Please provide a step-by-step plan in plain English, with practical actions and the safest possible next steps."

### Example 3: Ask for debugging help

"Act as a debugging coach. I am seeing [issue]. I need help finding the cause and the best fix. Explain the root cause in simple terms, list the likely reasons, and give me the safest next steps."

### Example 4: Ask for repository help

"Act as a senior technical assistant for a beginner. I am working in this repository and need help understanding what is important. Please explain the structure, critical files, and the best way to start. Keep the answer simple and avoid jargon."

## Prompt quality checklist

Before sending a prompt, check:

- Is the goal clear?
- Did I mention the context?
- Are constraints defined?
- Did I say what output I want?
- Did I ask for plain English if I am a beginner?

## Best practices

- Be specific
- Ask for structure
- Ask for simple language
- Ask for explanations and not just actions
- Ask Claude to explain what it is doing when needed

## When prompts go wrong

Weak prompts often fail because they are missing one of these:

- unclear goal
- too much information mixed together
- no output format
- no constraints
- vague wording
- no role assignment

## Prompt upgrade formula

If your prompt is weak, upgrade it like this:

"Act as [role]. I need help with [task]. I am a beginner and want the answer in simple English. Context: [brief details]. Constraints: [rules]. Please give me: [output list]."

## Example final prompt

"Act as a senior technical mentor for a beginner. I want help understanding how to work with this repository and improve my results with AI. Context: I am not technical and want clear instructions. Constraints: explain everything in plain English, avoid unnecessary jargon, and give practical, safe steps. Please provide: 1) a short summary, 2) the key files to inspect, 3) the most useful commands to run, 4) a troubleshooting section, and 5) a suggested action plan."

This is the kind of prompt that gets much better results.
